# 地下水貯留量WebGIS設計

利用者が承認した構成：静的配信、3D柱、地点時系列グラフ。細部は実装者に委任。

MapLibre GL JSの世界地図にdeck.glの柱を重ね、地下水貯留量の偏差を可視化する。青が増加、橙が減少、高さは偏差の絶対値。単位はmm相当水高で、柱は視認性のため誇張する。基準期間2003～2022年と実効空間解像度約250～300 kmを説明する。

世界を初期表示し、地域プリセット、3D/2D切替、高さ調整、月選択、再生速度、再生停止を設ける。選択セルの座標、値、不確実性、全期間の折れ線グラフとCSV出力を表示する。欠測月は空白として表示し、線を接続しない。読み込み中、取得失敗、データ未導入、WebGL非対応の状態を明示する。画面は日本語で、狭い画面では情報パネルを地図下へ配置する。

SvelteKit 3、Svelte 5、Tailwind CSS、TypeScriptを利用する。不要なclass、any、unknown型を導入しない。値・期間・解像度はデータのメタデータから取得する。

CDSの公式NetCDFをPythonで事前変換し、月ごとの圧縮バイナリと地点時系列用の分割バイナリを生成する。格子インデックスと座標を固定して配列を対応付ける。Float32を利用し、欠損はNaN。JSONメタデータに取得日・元ファイルSHA256・出典・バージョン・基準期間・観測月・欠測月を含める。実データの未取得をサンプルで偽装しない。

GitHub Pagesで静的配信するため、NetCDFをブラウザーで毎回読み込む方法やAPIサーバー方式を採用しない。前者は初回転送が大きく、後者は公開先と合わない。ソースと変換済みデータを公開し、GitHub Actionsで型検査・テスト・ビルド後にPagesへデプロイする。秘密情報を公開しない。

データの提供末尾は現時点で2023年9月。現在月までの未提供値は生成しない。更新は新しい公式ファイルの取得・再変換で反映可能にする。公式仕様と検証要件は調査記録を参照。
